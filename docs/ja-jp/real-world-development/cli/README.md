**[GitHub Copilot CLI](https://docs.github.com/copilot/concepts/agents/about-copilot-cli)** は、ターミナルで GitHub Copilot をエージェント型のコーディング アシスタントとして利用できるようにします。コードベースを探索し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンド ラインから行えるため、グラフィカル エディターに切り替えずに作業の流れを保てます。

ワークショップは、1つの継続した Tailspin Toys ワークフローに沿って進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして作業環境を確認します。
2. 対象を絞った星評価の変更を行い、ブラウザーでレビューして、最初の pull request (PR) を手動でマージします。
3. フィルター Issue を起点にし、Plan モードでアプローチを定義し、Autopilot モードで構築し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックに使用します。
6. Playwright Model Context Protocol (MCP) server を追加し、ブラウザーでフィルター機能を確認します。
7. 品質保証 (QA) カスタム エージェントを作成し、要件、カバレッジ、検証の証拠をレビューします。
8. フィルター機能の変更全体をレビューし、フィルター PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、任意のクラウド委任に関するスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、2つの PR を作成します。星評価、続いて指示の更新、スキルの更新、QA プロファイル、テストを含むフィルター機能です。フィルター機能と品質ワークフローでは1つの会話とブランチを共有し、各ツールを確認しながら作業を積み重ねます。

## 前提条件

このワークショップに参加する前に、次を準備してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] ターミナル / コマンド ライン操作の基本的な知識
- [ ] インストール済みで設定済みの Git

> [!TIP]
> 有料プランがありませんか。認証済みの学生は [GitHub Education][callout-student-plan-education] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用する agent、MCP、code review、Copilot CLI の機能が含まれているため、すべての harness を完了できます。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
