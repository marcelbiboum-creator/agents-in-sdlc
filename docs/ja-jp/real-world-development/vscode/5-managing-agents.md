GitHub Copilot をエージェント モードにすると、コードベースを調査し、変更案を提示し、ファイルを編集し、コマンドを実行します。作業は自分のマシンでリアルタイムに進むため、VS Codeの Copilot Chatにはツール呼び出しとファイル編集をリアルタイムで表示できます。各差分をインラインで確認し、個別の変更を受け入れたり拒否したりし、フォローアップ プロンプトで作業を調整できます。

この演習では、次の内容を学習します。

- アクセシビリティ エージェントの作業をリアルタイムで監視する。
- 提案されたファイル編集をレビューして受け入れる。
- セッション中にエージェントを方向付けし、ハイコントラスト モードと併せてライト モード切り替えを追加する。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタム エージェントがハイコントラスト モードを実装しています。作業の進行中に、デザイン チームからライト モード切り替えの追加要求がありました。既存セッションを方向付けし、作業を拡張します。

## Copilot の進捗を監視する

Copilot Chatビューには、エージェントが実行する各ステップ、調査ファイル、実行コマンド、提案編集が表示されます。

1. 演習 4の Copilot Chatビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツール呼び出しと編集を確認します。
3. エージェントがファイル編集を提案したら、差分が表示されます。
   - **Keep**を選択して変更を受け入れます。
   - **Undo**を選択して変更を取り消し、エージェントに再試行させます。
4. チャット上部の**Files changed**インジケーターを開き、このセッションでエージェントが変更したファイルの全体を確認します。

> [!NOTE]
> ターミナル コマンドなどのツール呼び出しで権限が必要な場合は、エージェントが停止し、**Allow**プロンプトを表示します。実行してよいコマンドだけ承認してください。

5. エージェントがハイコントラスト モードの実装を完了するまで待ちます。変更を要約した最終メッセージが表示されます。

## エージェントにライト モードを追加させる

ハイコントラスト モードを実装したら、同じ会話を使ってライト モード切り替えを追加します。同じチャット セッションを続けるため、エージェントは以前の作業コンテキストを保持しています。

1. Copilot Chatの入力欄に次のフォローアップ プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは作業を継続し、すでに行った変更を調査し、ライト モードの追加案を提示します。
3. ハイコントラスト モードと同じように各編集を確認し、**Keep**または**Undo**を選択します。
4. エージェントが望ましくない方向へ進んだ場合は、チャット入力欄横の**Stop**ボタンで停止し、フォローアップ メッセージで修正を指示します。

> [!TIP]
> セッション中に方向付けする方が、やり直すより速い場合があります。調整を依頼したり、方向修正したり、スコープを拡張したりするにはフォローアップ プロンプトを使います。

## 変更ファイルを確認する

コミット前に、エージェントが変更したすべてを確認します。

1. VS Codeの**Source Control**ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストの更新が表示されます。
3. 変更されたファイルをいくつか開き、差分を確認します。ARIA 属性、キーボード ナビゲーション、セマンティック HTML、ローカルストレージによる永続化など、アクセシビリティ パターンが反映されていることを確認します。
4. 問題がなければ、変更をステージしてコミットします。[次のレッスン][next-lesson]で公開します。

## まとめと次のステップ

Copilot Chat エージェント モードを使って進行中のセッションを監視し、各ファイル編集をレビューし、変更を受け入れまたは拒否し、フォローアップ プロンプトでコンテキストを失わずに作業を拡張しました。

このレッスンでは、次の内容を確認しました。

- エージェントの作業をリアルタイムで監視する。
- 個別のファイル編集を受け入れまたは拒否する。
- フォローアップ プロンプトでセッションを中途から方向付けする。

[次のレッスン][next-lesson]では、アクセシビリティ作業を pull requestとして公開し、ローカル カスタム エージェントが生成した変更をレビューします。
